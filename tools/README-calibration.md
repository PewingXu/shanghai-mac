# 足垫压力标定（ADC → kPa / N）

主程序采集页的「压力」是 ADC 值总和（0～255 每格），不是物理压强。用 `tools/calibrate_pressure.html`
做一次标定，得到单个传感点的 ADC → kPa 公式，再接进主程序即可显示真实压强与总力。

## 一、打开工具

直接用 Chrome / Edge 打开 `tools/calibrate_pressure.html`（双击即可，不需要服务器）。

足垫接入有两条路，选一条：

| 场景 | 按钮 | 说明 |
|---|---|---|
| 主程序（`pnpm dev` 或安装版）正在跑 | **后端桥** | 订阅后端 WebSocket 帧流，不抢串口，主程序和工具同时看帧 |
| 主程序没开 | **串口** | 浏览器直连足垫，3,000,000 波特。后端在跑时会报占用，改用后端桥 |

工具用的帧协议、方向翻转、转置与主程序完全一致（4096 字节 + `AA 55 03 99`，`FRAME_FLIP_*` 两个开关，显示 `D[r][c] = M[c][r]`），
中栏 64×64 图上按哪儿亮哪儿，左半左脚、右半右脚、脚尖朝上，和采集页 2D 视图一模一样。

## 二、准备的东西

- **刚性平压板**：铝块或有机玻璃板，推荐 50×50 mm 或 70×70 mm（7mm 格距，尽量盖整数格、边缘对齐格线）。
- **砝码**：一组 1 kg 或 2 kg，能叠到预期最大压强。成人站立足底平均约 50～200 kPa，局部（跟骨、跖骨头）可到 300～400 kPa。
  50×50 mm 压板上 1 kg ≈ 3.9 kPa，要到 200 kPa 需约 50 kg，所以**用小压板**：
  20×20 mm 压板上 1 kg ≈ 24.5 kPa，8 kg 就到 196 kPa。
- 或者一台串口压力计（ADC-N 那类，2400 波特输出 `000.00`），工具照参考项目支持，不是必需。

## 三、标定步骤

1. 连接足垫，确认中栏 fps 在跳、按一下垫子对应格子会亮。
2. 左栏 ② 填压板尺寸；把**压板本身的质量**填进「底重」（它压在垫子上，是真实载荷）。
3. 垫子**空载**时点 ③「⊘ 空垫去皮」。
4. 勾 ③′「启用手动输入」，选「砝码」，填单块砝码质量。
5. 把压板放到垫子中央平坦处，观察中栏：
   - 默认 ROI「自动」= 所有 ADC > 阈值的格子。压板边缘外有零散噪点时切「框选」，在图上拖一个刚好套住压板的框。
6. 放第 1 块砝码 → 点「＋ 加一块」→ 等右上角变「读数稳定」→ 按 **空格** 记录。
7. 再放一块 → 「＋」→ 稳定 → 空格……重复 8～12 级。前几级密一点（0.5 kg 一档），后面 1～2 kg 一档。
8. 全部卸掉再记一个 0 点（可选，压路径回程看滞回）。
9. 右栏 ⑥ 选 **x = 有效点 ADC 均值，y = 压强 kPa，幂函数**。看 R²，一般 > 0.99 才算好。
10. 点「复制 接入主程序的 TS 片段」，另外「导出 CSV」留档。

换一块压板重复一遍，两条曲线应该基本重合。不重合说明压板边缘格子没压实（用更厚的板）或 ROI 圈进了没压到的格子。

## 四、为什么拟合 x = 单点均值、y = kPa

传感器是每个格子独立的压阻元件，物理关系是 **单格 ADC ↔ 单格压强**，与压板多大无关。
标定出 `adcToKpa(v)` 后，主程序对整帧逐格换算：

```
总力 N        = Σ adcToKpa(v) × 1000 × 49e-6      （单格 49 mm²）
平均压强 kPa  = 总力 / (有效格数 × 49e-6) / 1000
```

任何脚型、任何接触面积都成立。而「x = ADC 总和、y = N」那种拟合只在接触面积等于标定压板时成立，脚一换就错，工具里保留它只是做对照。

压阻传感器通常是幂函数关系 `kPa = a·(ADC − x₀)^b`，b 常在 1.2～2.5 之间，`x₀` 是起压阈值。线性拟合在低压段会明显偏离。

## 五、接进主程序

复制出来的片段贴到 `client/src/lib/pressureCalib.ts`（新建），然后在 `client/src/pages/MeasurePage.tsx` 的 `handleFrame` 里：

```ts
// 原来
const pressure = sum;
// 改成
const pressure = frameToNewton(frame, threshold);   // 单位 N
```

HUD 的单位从 `pa` 改成 `N`，或再除以接触面积显示 kPa（`frameMeanKpa`）。后端 Python 分区压力占比用的是 ADC 相对值，不受影响，不用改。

## 六、导出 CSV 字段

`adc_sum_roi` ROI 内 ADC 总和（已扣基线）· `adc_mean_active` 有效点均值 · `active_cells` 有效格数 · `adc_peak` 峰值 ·
`gauge_kgf` 施加质量 · `dead_load_N` 底重 · `total_N` 总力 · `area_mm2` 压板面积 · `pressure_kPa` · `roi` · `noise_th` 噪声阈值 · `stable`。
最后一行 `# fit,…` 是当时的拟合公式。CSV 可用「导入 CSV」读回继续拟合。
